# Legendary eyewear

27 Legendary designs use 18 vanilla eyewear bases. Each item has its signature and four distinct bonuses, rolled deterministically for that item instance.

## Random bonuses

| Bonus | Range | Effect |
| --- | --- | --- |
| Clear Head | 20–30% | Shorter concussion duration |
| Afterimage | 20–30% | Shorter flashbang blindness duration |
| Steady Gaze | 10–30% | Less aiming sway |
| Quick Focus | 15–25% | Faster aiming speed |
| Light on the Eyes | 10–30% | Lower arm-stamina drain while aiming |
| Follow Through | 10–15% | Less recoil while aiming |
| Close Focus | 15–25% | Tighter hip-fire spread while stationary |
| Moving Picture | 20–30% | Less aiming sway while walking |
| Keen Appraiser | 25–50% | Faster search speed |

Same-stat reductions multiply the remaining amount. For example, two 30% sway reductions yield 51% less sway. 20/20 excludes Clear Head because it already prevents concussion.

## Equipment and spawning

Eyewear uses its own `eyewear` category in the server spawn settings. Existing category values are preserved. Defaults are 1% for PMCs, Scavs, other eligible factions and container conversions, and 10% for bosses. Only supported vanilla bases are converted; attachments and third-party item templates remain unchanged.

Bots use only supported combat effects. Stamina, HUD, looting, and human-only preparation checks do not run for bots. Removing eyewear clears prepared wearer effects; cooldowns survive swapping. Fired projectiles, grenades and placed smoke finish within their bounded lifetime. Raid exit clears wearer state and cancels pending work.
